# راهساز ماشین — وب‌سایت تک‌صفحه‌ای

## ساختار پروژه
```
rahsaz-machine/
  index.html
  css/style.css
  js/app.js
  skills/
    frontend-design/SKILL.md      ← از قبل در دسترس، برای طراحی استفاده شد
    video-to-website/SKILL.md     ← فایلی که آپلود کردید (بدون ویدیو استفاده نشد، فقط الهام‌بخش موشن)
    ui-ux-pro-max/NOTE.md         ← توضیح اینکه چرا این ابزار CLI نصب/اجرا نشد
```

## نکته مهم درباره فونت «کلمه» (Kalameh)
فونت کلمه یک فونت **پولی و دارای مالکیت مادی** است (طراح: سید ناصر خادم، فروشنده انحصاری:
fontiran.com) و به‌صورت رایگان روی هیچ CDN عمومی و قانونی موجود نیست، بنابراین من نتوانستم
آن را دانلود/جاسازی کنم.

فعلاً سایت با فونت **Vazirmatn** (رایگان و متن‌باز، از Google Fonts) کار می‌کند که از نظر
حس بصری (فونت هندسی، خوانا، مناسب تبلیغات) نزدیک‌ترین جایگزین رایگان به کلمه است.

برای جایگزینی با فونت کلمه‌ی واقعی (بعد از خرید لایسنس وب از fontiran.com):
1. فایل‌های `kalameh-regular.woff2` و `kalameh-bold.woff2` را در پوشه‌ی `fonts/` قرار دهید.
2. در `css/style.css` بلوک `@font-face` بالای فایل از قبل آماده و فعال است — فقط کافیست
   فایل‌ها را در مسیر گفته‌شده کپی کنید و رفرش بگیرید.

## تصاویر
هر جایی که عکس واقعی لازم است (هیرو، انبار/فروشگاه، لوگوی XCMG، لوگوی Shantui) یک باکس
placeholder با خط‌چین و برچسب گذاشته شده (کلاس `.img-placeholder`، با `data-slot` مشخص).
هروقت عکس‌ها را فرستادید، همین باکس‌ها را با `<img>` واقعی جایگزین می‌کنم.

## اجرای محلی
```
npx serve .
# یا
python -m http.server 8000
```
سپس مرورگر را روی آدرس داده‌شده باز کنید. (فایل باید از طریق HTTP سرو شود، نه با باز کردن مستقیم file://، تا فونت و نقشه درست بارگذاری شوند.)

## فرم مشاوره
فرم فعلاً فقط نمایشی است (طبق درخواست شما) — پیام موفقیت نمایش داده می‌شود ولی داده‌ای
ارسال نمی‌شود. هروقت خواستید به ایمیل، واتساپ یا یک سرویس فرم واقعی وصل شود، بگویید.

## ویدیوی پس‌زمینه بخش CTA پایانی
فایل ویدیوی خودتان را دقیقاً با همین نام و مسیر قرار دهید:
```
media/cta-bg.mp4
```
همین که فایل در این مسیر باشد، بخش CTA پایانی (همان بخش تیره‌ی «برای هر مدل لودر چینی...»
درست قبل از فوتر) به‌صورت خودکار آن را به‌صورت loop و بی‌صدا پخش می‌کند (کد مربوطه در
`index.html` — تگ `<video class="cta-final-bg-video">` — از قبل آماده است). پیشنهاد:
کلیپی ۱۰ تا ۲۰ ثانیه‌ای و نه‌چندان شلوغ چون متن روی آن قرار می‌گیرد.

## استوری‌های دسته‌بندی محصولات (بخش محصولات)
فقط ۳ دسته باقی مانده: موتور (۴ ویدیو)، شاسی و زنجیر (۱ ویدیو)، الکتریکی (۱ ویدیو).
کد از قبل به این مسیرها وصل است — کافی است فایل‌های خودتان را دقیقاً با همین نام‌ها در
پوشه‌ی `media/stories/` ذخیره کنید، نیازی به تغییر کد نیست:

```
media/stories/engine-1.mp4
media/stories/engine-2.mp4
media/stories/engine-3.mp4
media/stories/engine-4.mp4
media/stories/chassis-1.mp4
media/stories/electrical-1.mp4
```

کاور هر کارت (تصویری که روی نوار متحرک دیده می‌شود) همان ویدیوی شماره ۱ همان دسته است
(مثلاً کاور کارت «موتور» = `engine-1.mp4`)، پس همین‌که فایل‌ها را در مسیر بالا بگذارید،
هم کاور کارت‌ها و هم محتوای داخل استوری خودش را به‌روز می‌کند.

اگر بعداً خواستید تعداد ویدیوهای یک دسته را تغییر دهید یا دسته‌ی جدیدی اضافه کنید، در
فایل `js/app.js` دنبال آرایه‌ی `storyCategories` بگردید و آیتم اضافه/کم کنید؛ بقیه‌ی
رفتار (نوار متحرک، باز/بسته شدن استوری، ناوبری قبلی/بعدی، نوار پیشرفت) خودکار هماهنگ
می‌شود.
