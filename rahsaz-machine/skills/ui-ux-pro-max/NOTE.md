# درباره‌ی ui-ux-pro-max-skill

این skill (نسخه‌ی basic ریپوی nextlevelbuilder/ui-ux-pro-max-skill) یک ابزار CLI مبتنی بر
Python/npm است که باید با دستوراتی مثل `npm install -g ui-ux-pro-max-cli` و
`uipro init --ai claude` روی سیستم شما نصب بشه و اسکریپت‌های پایتون آن به صورت محلی
اجرا می‌شن.

من (Claude) این کار رو در محیط این پروژه انجام ندادم، به دو دلیل:

1. **دسترسی شبکه‌ی من در این session غیرفعاله** — پس اصلاً نمی‌تونم `npm install` یا
   `git clone` بزنم.
2. **اصل احتیاطی**: نصب و اجرای خودکار یک پکیج npm/اسکریپت پایتون ناشناس از یک ریپوی
   بیرونی، حتی اگر معتبر به نظر برسه، کاری نیست که به‌صورت خودکار و بدون تأیید شما انجام
   بدم — چون می‌تونه کد دلخواه روی ماشین اجرا کنه.

**چیزی که در عوض انجام دادم:** صفحه‌ی README این ریپو رو خوندم (فقط متن مستندات، نه کد
اجرایی) و اصول طراحی‌ای که تبلیغ می‌کنه (تطبیق صنعت با پالت رنگ، تایپوگرافی، و الگوی
صفحه) رو به‌صورت دستی و با قضاوت خودم، هماهنگ با راهنمای frontend-design داخلی، روی
پروژه‌ی شما پیاده کردم — بدون اجرای هیچ اسکریپتی.

اگر می‌خواید واقعاً از نسخه‌ی CLI این ابزار روی سیستم خودتان (نه در این چت) استفاده کنید،
باید خودتان دستورات بالا رو در ترمینال شخصی‌تون اجرا کنید:

```
npm install -g ui-ux-pro-max-cli
uipro init --ai claude
```
